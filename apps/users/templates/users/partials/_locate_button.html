Turn location on for this site

iPhone: Settings → Privacy & Security → Location Services → turn it on, then Safari Websites → While Using the App. Come back and tap the button again.

Android (Chrome): tap the icon left of the web address → Permissions → Location → Allow. Then tap the button again.
